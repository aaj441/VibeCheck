# Social Interaction Coach - Neurodivergent Support System

A comprehensive, empathetic coaching application designed specifically for neurodivergent individuals preparing for social interactions including dates, interviews, networking events, and casual social situations.

## 🌟 Key Features

### 🧠 **Neurodivergent-Centered Design**
- Built with ADHD, autism, and social anxiety considerations
- Sensory-friendly interface with calming colors
- Clear, step-by-step progression
- Customizable experience based on individual needs

### 📋 **6-Step Coaching Process**
1. **Context Check-In** - Understanding your upcoming event
2. **Emotional Calibration** - Mood assessment and trigger identification  
3. **Personalized Checklist** - Custom preparation based on your needs
4. **Practice & Simulation** - Safe space to rehearse responses
5. **Live Support** - Real-time encouragement during events
6. **Post-Reflection** - Growth-focused processing and celebration

### ♿ **Accessibility First**
- WCAG 2.1 AA compliance target
- Screen reader friendly
- Keyboard navigation support
- High contrast mode
- Reduced motion options
- Multiple input methods

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Backend Setup
```bash
cd houses-app/backend
npm install
npm run dev
```
Server runs on `http://localhost:3001`

### Frontend Setup  
```bash
cd houses-app/frontend
npm install
npm run dev
```
App runs on `http://localhost:3000`

## 💙 Design Philosophy

### **Empathy-Driven**
Every interaction is designed to be supportive, non-judgmental, and affirming of neurodivergent experiences.

### **Strengths-Based**
Focuses on leveraging unique neurodivergent traits as strengths rather than deficits to overcome.

### **User Agency**
Users maintain full control over their experience, pacing, and level of engagement.

### **Progress Over Perfection**
Celebrates small wins and growth rather than demanding flawless social performance.

## 📖 Usage Examples

### For a Job Interview
1. **Context**: "I have a software engineering interview tomorrow via video call"
2. **Emotions**: Anxiety: 8/10, Energy: 6/10, Focus: 7/10
3. **Checklist**: Research company, prepare STAR method examples, test video setup
4. **Practice**: "Tell me about yourself" scenarios with feedback
5. **Live Support**: Real-time encouragement during interview
6. **Reflection**: Celebrate asking thoughtful questions, plan follow-up

### For a First Date
1. **Context**: "Coffee date with someone from a dating app"  
2. **Emotions**: Excitement: 7/10, Anxiety: 6/10, triggers: crowded spaces
3. **Checklist**: Choose quiet café, prepare conversation topics, plan exit strategy
4. **Practice**: Greeting scenarios and handling awkward pauses
5. **Live Support**: Quick confidence boosts via discrete messaging
6. **Reflection**: Acknowledge authentic moments, plan potential second date
